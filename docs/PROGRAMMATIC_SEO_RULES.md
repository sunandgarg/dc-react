# Programmatic SEO rules

## Indexability gate

Programmatic URLs must be canonical, return HTTP 200, match a supported filter vocabulary and contain useful live records. Filter sitemap pages require at least three matching entities. Empty, arbitrary-search, sort-only and tracking-parameter pages remain out of the sitemap and are `noindex`.

## Allowed page families

- College, course and exam entity pages and useful detail tabs
- Curated ranking and discovery pages
- Live location, stream, group, mode, specialization and approved facet combinations
- Editorial news, author, career, scholarship and study-material pages

## Quality rules

- Never create URLs solely because a parameter combination exists.
- Keep titles, H1s, summaries and links specific to the selected intent.
- Use database facts; omit unknown values instead of inventing fallbacks.
- Do not index near-duplicate combinations that present the same result set and copy.
- Add at least one useful path back to the parent directory and relevant entities.

## Scale control

New templates must ship behind tests for canonical URL, robots, status, sitemap membership, schema and minimum data completeness. Expand inventory only after representative live pages pass those checks.
